PDFRapid — User guide

PDF viewer and editor for Windows · version {version}

1. Getting started

  • Open: File → Open PDF (Ctrl+O), drag the file onto the window, or "Open with → PDFRapid" in Explorer. Each document opens in its own tab (Ctrl+Tab to switch).
  • Save: Ctrl+S saves over the same file; Ctrl+Shift+S saves a copy. What you add (text, shapes, signatures…) is saved as standard PDF annotations: visible in any reader and still editable in PDFRapid.
  • Undo: Ctrl+Z and Ctrl+Shift+Z. If the program closes unexpectedly, it offers to recover autosaved changes the next time it starts.
  • Zoom and pages: Ctrl+mouse wheel, Ctrl++ / Ctrl+-; Ctrl+G to go to a page; Alt+← / Alt+→ to go back or forward.

2. Sidebar tools

Each tool has a key (no Ctrl). Press Esc to return to Select. With the Select tool (V) you can move, resize, rotate, duplicate (Ctrl+D) or delete any object; right-click for more options (colour, width, order…).

Arrange objects (right-click one or several): align and distribute (with a single object, relative to the page), flip, Position and size… in millimetres, group and ungroup (one click selects the whole group), lock or hide (recover them by right-clicking an empty area; hidden objects are not printed), and copy and paste format between objects.

3. Search

  • Quick find (top bar or Ctrl+F): type and use the arrows or Enter / Shift+F3 to move between results; the current one is highlighted in yellow.
  • Search in folder (Ctrl+Shift+F): finds text in every PDF in a folder.
  • If the PDF is scanned (an image with no text), run OCR first (View → Panels → OCR) so it can be searched and copied.

4. Pages

  • In the thumbnails panel you can reorder by dragging, and right-click to rotate or select a range.
  • Document → Pages: crop margins, watermark, header and footer with free text ({n}, {total}, {date}, {name}), Bates numbering and page background (colour or image).
  • The Operations between PDFs tab lets you merge several PDFs (choosing the order), split one into several, insert blank pages and move pages between documents.

5. Forms and comments

  • Form fields are filled in directly on the page; the Form panel lists them.
  • Create forms: Document → Form → Add (or “Add field” in the panel). Click where the field goes, or drag to size it, and choose its name, tooltip, default value, options and whether it is required. Types: text, multi-line text, check box, radio button (buttons in the same group are mutually exclusive), drop-down list and list box. The ⋯ button of each field lets you change its properties, move it or delete it; everything can be undone.
  • Detect fields: Document → Form → Detect fields automatically… looks for lines to write on (“Name: ____”), underscores, check boxes and empty boxes, and creates a field on each one named after its label. Review them in the Form panel; Ctrl+Z removes them all. In a scanned PDF it finds nothing: use Fill & Sign.
  • Measure (Q): the button's arrow chooses Distance (drag), Perimeter or Area (click each vertex; double-click or Enter finishes, Backspace removes the last one, Esc clears). For drawings, «Drawing scale…» converts measurements, for example 1 cm on paper = 1 m.
  • Read aloud: View → Read aloud reads the page (Ctrl+Shift+V), to the end (Ctrl+Shift+B) or the selected text, with the Windows voices. Ctrl+Shift+P pauses and Ctrl+Shift+E stops.
  • Spelling: when typing text, boxes and comments, unknown words are underlined in red; right-click for suggestions, add them to the dictionary or ignore them (Edit → Preferences → Spelling).
  • Split by bookmarks: in Operations between PDFs → Split, «By bookmarks» creates one file per chapter named after the bookmark.
  • Fill & Sign (key J): places a check ✓, a cross ✗, a dot, a line, today's date or your initials with one click. The button's arrow chooses the symbol; size and colour follow the format bar.
  • Document images: right-click an image of the PDF → convert it into an object (move, resize, rotate or crop it), replace it, save it as PNG/JPEG or delete it. If the image repeats (a logo on every page), replacing or deleting it changes it everywhere.
  • Links: Document → Links → Add link (draw the area and choose a page or a web address); “Manage links” lets you change or delete them.
  • Reply to comments: double-click a comment to reply and set its status (accepted, rejected, cancelled, completed). Replies are also shown in Acrobat.
  • Clear form (the panel’s “Clear” button) returns every field to its default value.
  • The Comments panel (Ctrl+Shift+C) lists every annotation in the document so you can review or jump to it; you can filter by type, status, author or text, and «Summary…» creates a PDF with the comments shown.
  • Flatten (Document → Flatten annotations and forms) turns everything into fixed page content: useful before sending a document that must not be changed.

Print, export and batch processing

  • Print (Ctrl+P): choose pages, with or without comments, actual or fitted size, multiple pages per sheet, booklet (double-sided, short edge) or poster across several sheets; then the preview.
  • Export (File → Export): Word, Excel (each table on a sheet), text, HTML, Markdown (headings by font size, lists, bold, tables and links; no images), images or PDF/A.
  • Batch processing (Document): apply OCR, compression, watermark, numbering, password, PDF/A, flattening, scrubbing or export (text, Excel or Markdown) to every PDF in a folder. Originals are not changed.

6. Signing

Handwritten signature (key K): an image of your signature. Handy for informal documents, but it is not a legally valid electronic signature.

Electronic signature with a certificate (signature button on the top bar or Document → Signatures → Sign with digital certificate):

  1. Choose where the certificate is: a .p12/.pfx file, a USB token or smart card, or a certificate installed in Windows.
  2. Choose the stamp style (text or with a QR code) and its size; a box follows the mouse: click where the signature should go.
  3. Optional: a timestamp from a server (TSA) and long-term validation (LTV), which stores in the document what is needed to check the certificate many years from now. Both need internet at that moment.

PDFRapid never stores the certificate password or the token PIN. The Digital signatures panel shows who signed, whether the document changed afterwards and whether the signature is long-term.

QR magnifier (top-bar button or key W): hover over a QR code to read its content in a small window; click to copy it.

7. Protect and archive

  • Password: Document → Protect → Password protect (to open and/or printing and copying permissions).
  • Permanent redaction: mark areas (key E) or search for text to redact, then "Apply permanent redaction". The content underneath is removed from the file, not just covered.
  • Remove hidden information: metadata, attachments, JavaScript, links to files and thumbnails.
  • PDF/A (File → Export → As PDF/A): creates a long-term preservation copy (PDF/A-2b), as many agencies and archives require. It embeds fonts and the colour profile and removes anything that might stop working. For a signed PDF/A, convert first and then sign the copy.

8. Create and convert

  • File → Create PDF: from images, from Word/Excel/PowerPoint (uses Office or LibreOffice if installed) or from the scanner.
  • File → Export: to Word (.docx), pages as images, PDF/A.
  • Document → Compress PDF reduces the size (images and clean-up); Document → Compare with another PDF shows the differences.

9. Security and privacy

  • PDFRapid works offline: it never sends your documents anywhere. Only the timestamp and long-term validation, if you turn them on, contact a server.
  • It does not run PDF JavaScript. Links open only if they are web or e-mail links, and always after asking. Attachments open only if they are known document types.

10. Troubleshooting

  • "I can't select or search text": the PDF is a scanned image; use OCR.
  • "The document is protected": the author restricted copying or editing; you need the permissions password.
  • "The signature shows as invalid in another program": usually that program does not trust the authority that issued your certificate; install the authority's root certificate.
  • Log: if something goes wrong, the pdfrapid.log file in your user folder helps find the cause.

In-app help: F1 shows the help for the window, panel or tool you are using, the ? button of each window does the same, Shift+F1 opens the Help center with search and Ctrl+F1 shows every keyboard shortcut.
